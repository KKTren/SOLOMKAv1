# CQB СЕЛО — планировщик поля

## Обновление «Соломки»: свободные углы и 3D

Откройте `index.html` в браузере — сборка уже готова, установка не нужна.

- **Стена под любым углом**: выберите инструмент и проведите от начала до конца стены. Длина при растягивании меняется целыми тюками; направление остаётся свободным. Горизонтальный и вертикальный инструменты также сохранены.
- **Новая стена → Ярусов новой стены**: заранее выберите от 1 до 6 ярусов. Рядом показана высота; при рисовании видны тюки в ряду, ярусы и общее количество. Настройка применяется к следующим стенам, существующие стены не меняются.
- **Поворот, °** в свойствах выбранного объекта: поворот стены или предмета вокруг его начальной точки. После поворота объект можно выбирать и перемещать как обычно.
- **Размер тюка, м** в панели построения: длина, ширина и высота. Они применяются ко всей карте, влияют на расчёт количества и сохраняются в файле карты, в библиотеке браузера и в ссылке.
- **Привязка → Нет**: свободное рисование без привязки к сетке.
- **3D-просмотр** в панели построения или меню «Карта»: вращайте модель мышью/пальцем, меняйте наклон и приближение. Кнопка «К человеку» приближает фигуру ростом ровно 1,80 м; её положение задаётся координатами X и Y.

На телефоне настройки доступны в панели построения; 3D-просмотр также доступен через меню «Карта».

Старые карты открываются с размером тюка 2 × 0,8 м. Начальная высота принята равной 0,8 м: замените её результатом замера. Новые стены рисуются целыми тюками. В старых стенах или при ручном вводе произвольной длины неполный последний участок отображается укороченным, а в расчёт входит целый тюк. Колонна занимает один полный тюк в плане, штабель — два соседних тюка. Прочие предметы в 3D показаны условными объёмами; подложка отображается в обычном плане.

Проверено: сборка, диагональ с известной длиной, поворот стены, размеры и сохранение карты, пересчёт тюков, геометрия 3D и изменение ракурса, свободное рисование без сетки. Полная визуальная проверка в браузере в среде подготовки недоступна.

Планировщик CQB/спидсофт-поля из тюков сена: стены, зоны, расчёт тюков и сметы, пул турнирных карт и правила игры.

Сайт: https://kktren.github.io/SOLOMKAv1/

## Пул карт — папка `maps`

Каждая карта турнира — отдельный файл `.json` в папке `maps`. Программа сама читает эту папку
(«Турнир → Пул карт…» или кнопка «Пул карт»).

Как добавить свою карту:

1. Нарисуйте карту в программе.
2. Откройте «Правила», выберите дисциплину и впишите правила этой карты.
3. «Файл → Сохранить файлом» — скачается `.json`.
4. Загрузите файл в папку `maps` на GitHub (Add file → Upload files). Через минуту карта появится в пуле.

`maps/index.json` — запасной список на случай, если GitHub API недоступен. Новую карту желательно дописать и туда.

Готовые карты: A · Мельница, B · Змейка, C · Амбар (5×5 флаг), D · Околица (3×3 огни), E · Плетень (дуэль).

## Правила

У каждой карты свои правила: дисциплина, параметры (игроки, время раунда, раунды, лимит Дж) и свой текст.
Дисциплины: 5×5 центральный флаг (Speedsoft Russia, SpeedQB), 3×3 огни (CSL), дуэль 1×1 / 2×2,
закладка бомбы (шаблон) и своя игра. Правила копируются текстом для чата или сохраняются в `.txt`.

## Сборка

`index.html` собирается из `CQBSelo.jsx`. Нужен Node.js 18+:

```
cd build
npm install
npm run build
```
